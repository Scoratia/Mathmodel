# 相变热影响分析

先看《平衡含水率与相变热分析.md》。本目录为新增机理对照与物理一致性审查，没有覆盖上一轮结果表。

这里的“平衡含水率”是药材与环境无净水分交换时的干基含水率，不是空气湿度。相变热已按实际排水质量流率计入，保留上一轮干物质守恒和显热输运。

本轮继承守恒修正版的密度取舍：初始密度来自题给公式，之后真实湿密度由质量与体积确定，未严格保留题给经验密度的全部变化。相变热计算仍沿用有效浓度边界；真实空气解释下是否满足蒸发方向，要看报告中的露点诊断。

results/study.json：耦合强度、网格、时间求解器、能量收支、湿空气诊断和物性验证。

results/history_q3.json、history_q4.json：温度、含水率、实际排水流率、半径与条件性露点时间序列。

results/question1_comparison.json：第一问30分钟温度对照。

使用requirements.txt对应的Python环境，按报告步骤执行。首次运行使用空临时缓存目录；修改输入文件后应换用新的空缓存目录，避免复用旧输入的缓存。代码与数据均在本目录，未使用商业软件求解，也没有借用其他药材的吸附参数。
