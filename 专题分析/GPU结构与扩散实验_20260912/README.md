# GPU结构与扩散实验：论文素材与复现实验

**先确认模型口径：本专题是经验热容量闭合、不计显式汽化热的对照实验。** 57.47/51.09 h属于这一闭合，不替代[根目录最终分析说明](../../最终分析说明.md)中的守恒显热、相变工况时长，也不直接证明相变模型下的敏感性。

本批运行107个情景，全部完成；15项CUDA验收通过。核心发现是：45组匹配扩散扰动保持Q4更快，但内部变形与边界定义的变化会使部分情景排序反转。它是确定性数值实验，不是真实样品实验，不产生统计置信区间。
